# 🍎 Fruit Blast

Яркая игра «Три в ряд» (VK Mini App) с бонусами, комбо и рекордами.

## Структура
- `index.html` — главная страница игры
- `css/` — стили
- `js/` — логика игры
- `leaderboard-worker/` — бэкенд таблицы лидеров на Cloudflare Workers (см. его README)

## Сайт
Игра доступна на GitHub Pages: https://miroden4ik.github.io/Fruit-Blast/
